# Statistics e-book

This book introduces the core ideas of statistics: describing data, probability, and drawing conclusions from samples. Read the chapters in order — each one builds on the previous.

Every chapter links to a Python notebook where you can try the same ideas on real numbers.

**How to use this book**

- Read a chapter, then work through its exercises before opening the solutions.
- Run the matching notebook in Colab and change the data to see what happens.
- Found a typo or an unclear explanation? Use **Suggest a change on GitHub** at the bottom of any page.

Pick a chapter from the sidebar to begin.
